Common HTML Tags outside <body>

Tags inside <body>
Tag Definition Examples
<!DOCTYPE html> This tag is saying what kind of code we are using (in this case html). This makes sure it's able to be read and displayed correctly. No examples applicable
<html lang="en"> Determines what the default language of the text on a page is. The language of this page is set to "en" (English).
<meta charset="UTF-8"> Determines what set of characters/alphabet this page is written with. No examples applicable
<title> </title> The text that shows up on the top bit of a tab in a browser.
<style> </style> Describes the internal CSS of a page. You can use this to change things like the color of text!
<link rel="stylesheet" href="styles.css"> Links to an external CSS file. This page and the previous one both point to a common styles.css file that controls how they look.
<link rel="icon" type="image/x-icon" href="..."> Adds a favicon (the little icon at the top of the tab).
