Common HTML Tags Outside <body>

Tags Definition Example(s)
<!DOCTYPE html> Sets document type *No examples
<html lang="en"> Sets website language This page is set to "en" for English. This tag helps websits such as Google Translate know the default language for this page is English
<meta charset="UTF-8"> Sets character in coding language *No examples
<title>...</title> Title of the webpage <title>a3</title>
<style>...</style> Section that describes the internal CSS of the page <style>font-family: Arial; Helvetica;</style>
<link rel="stylesheet" href="..."> Tag that points to an external CSS file <link rel="stylesheet" href="style.css">
<link rel="icon" type="image/x-icon" href="..."> Tag that adds a favicon <link rel="icon" type="image/x-icon" href="dizzy.ico">
