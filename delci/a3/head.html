<head> & others Tags Definition Example(s)
<!DOCTYPE html> informs the web browser about the version of HTML used in the document No Examples*
<meta charset="UTF-8"> defines the character encoding for the document No Examples*
<title>...</title> defines the document's title
<link rel="icon" type="image/x-icon" href="/images/favicon.ico"> small image displayed next to the title in the browsers tab
<style>...</style> section that describes the internal CSS of the page These lines will set the page's background color to black.

<style>
body {
background-color: black;
}
</style>
<link rel="stylesheet" href="style.css"> Tag that points to an external CSS file The homepage and this page point to a common style.css file that controls the look of these pages.
<html lang="en"> specifies the language of the element's content This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English
