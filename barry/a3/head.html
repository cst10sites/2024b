Common HTML Tags outside <body>

Body

Tags Definition Examples
<!DOCTYPE html>

Define the type of the document as html

 No examples
<html lang="en"> Set the default language of the page to English

This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8">

The charset attribute specifies the character encoding for the HTML document.

 No examples
<title>...</title> Set the title of your page.
<style>...</style> Section that describes the internal CSS of the page

<style>

background-color: black
}
</style>
<link rel="stylesheet" href="..."> Tag that points to an external CSS file

The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" type="image/x-icon" href="..."> Tag that adds a favicon
