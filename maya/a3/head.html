HTML/CSS Guide

Common HTML Tags Outside of Body

Tag Definition Examples
<!DOCTYPE html> This is a declaration that tells the browser what type of HTML the document is written in. No examples.
<html lang="en"> This specifies what language the document is written in. This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> This tag specifies which character set a website is written with. No examples
<title></title> This tag adds a title to your web page.
<style></style> This tag defines the style information for the document. <style>
body {
  background-color: black;
  color: white;
  margin: 25px 125px;
  font-family: "Trebuchet MS";
}
</style>
<link rel="icon" type="image" href="favicon.png"> Tag that adds a favicon
<link rel="stylesheet" href="style.css"> Tag that points to an external CSS file The homepage and this page point to a common style.css file that controls the look of these pages.
