Common HTML Tags outside <body>

Tag Definition Examples
<!DOCTYPE html> This a decraration that all HTML documents must start with to "tell" the browser what document type to expect. No example
<html lang="en"> This tag defines that the language of this website is english. Websites such as google translate use this tag to know the default language of this page, in this case english.
<meta charset="UTF-8"> This attribute specifies special character encoding for the HTML document so that specil characters can be used. No example
<title>. . . </title> Displays the title of the HTML document in the browser toolbar.
<style> . . . </style> This is a section that defines the internal CSS of a page. This section has been altered using the <style> tag.
<link rel="stylesheet" href=""> This tag points to an external CSS file. Both this and the home page have the same CSS file controling the way the pages look.
<link rel="icon" type="image/x-icon" href=""> The tag adds a favicon to the browser to tool bar of this page.
