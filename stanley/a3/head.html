Tag Definition Examples
<!DOCTYPE html> Declares the document type No examples*
<html lang="en"> Specifies the language of the element's content. This page is using the language "en" for English. This tag supports websites such as Google Translate know that the default language for this page is English.
<meta charset="UTF-8"> Specifies the character encoding as UTF-8. As a result, the web page can display text in multiple languages and special characters correctly. No examples*
<title></title> Title of the page The following image shows the title of this page:
<style></style> The HTML style attribute is used to add styles to an element, such as color, font, size, and more. The following code makes the background black.
<style>{
background-color:black;
}
<link rel="stylesheet" href="style.css"> The <link> tag defines the relationship between the current document and an external resource. The <link> tag is most often used to link to external style sheets or to add a favicon to your website. The <link> element is an empty element, it contains attributes only.
