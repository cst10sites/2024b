HTML guide

Common HTML tags outside <body>

Tag Definition Example(s)
<!DOCTYPE html> A "declaration" to the browser about what type the document is No examples
<html lang="en"> Specifies the language of the webpage This page is set to "en", which means English. This tag helps browsers know that this page is in English
<meta charset="UTF-8"> Specifies the character encoding in the HTML document, almost all webpages use UTF-8. No examples
<title>...</title> Defines the title of the webpage, it is shown in the webpage's tab in the browser.
<style>...</style> Section that describes the internal CSS of the page <style> body { background-color: black; } </style>
<link rel="stylesheet" href="styles.css"> Tag that points to an external CSS file The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" type="image/x-icon" href="/images/favicon.ico"> Tag that adds a favicon
