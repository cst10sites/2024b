Common HTML Tags inside <body>

<body> Tags Definition Example(s)
<!DOCTYPE html> All HTML documents must start with a <!DOCTYPE> declaration.
The declaration is not an HTML tag. It is an "information" to the browser about what document type to expect. 		No Possible Example
<html lang="en"> The lang attribute specifies the language of the element's content. This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> The charset attribute specifies the character encoding for the HTML document. No Possible Example
<title>...</title> The <title> tag defines the title of the document. The title must be text-only, and it is shown in the browser's title bar or in the page's tab.
<style>…</style> The <style> tag is the section that describes the internal CSS of the page
